# 哨站前端設計原型

在檔案總管用瀏覽器開啟 [原型選單](index.html)。原型可離線開啟，使用四台示範主機、同一批事件和固定趨勢樣本。按左上角的哨站圖示可回選單。

| 比較項目 | A 主機清冊 | B 即時監測 | C 事件中心 |
| --- | --- | --- | --- |
| 起點與版面 | 橫向導覽、狀態篩選列、清冊與右側詳情 | 窄側欄、滿寬跨主機圖、下方資源矩陣 | 工作區選單、待檢視摘要、事件時間軸與機房概況 |
| 找主機 | 依名稱、地區或 IP 搜尋，依狀態篩選 | 從資源矩陣選取主機，凸顯對應曲線 | 從事件或機房深入個別主機 |
| 圖表與用量 | 單機面積圖、各資源橫向量尺 | 多主機折線圖、分級著色的數值欄 | 事件主機的樣本柱狀圖、機房分段用量條 |
| 操作位置 | 新增主機在頂端，服務與重開機在主機詳情內 | 範圍與指標貼近主圖，主機操作集中在選定主機區 | 檢視與追查操作在事件詳情內 |
| 字體及密度 | 正黑體優先，標題與列距較寬，主機代碼用等寬字 | Segoe UI 優先，數值採等寬字，矩陣列距緊湊 | Noto Sans TC 優先，強調事件標題，時間與機房代碼採等寬字 |
| 手機操作 | 點清冊列跳到頁內主機詳情，資源數字移入詳情 | 固定頂部導覽，保留多線趨勢與完整資源矩陣 | 收合導覽，點事件後展開並定位至詳情 |

## 正式重建時要移植的功能

| 功能 | 現有流程與契約 | 原型提供 |
| --- | --- | --- |
| 主機狀態與歷史 | `GET /api/all` 使用 `X-Token`，回傳主機陣列，支援各主機增量歷史。 `GET /api/history` 依 `range`、可選的 `node` 讀取趨勢。正式版另有負載、網速、連線數、磁碟讀寫、程序、可用性與各類服務狀態。 | 清冊、三項資源、指定主機、示範服務與趨勢。 |
| 新增與管理主機 | `/api/peer`、`/api/pair-admin`、`/api/rename`。重新開機使用 `/api/reboot`，先申請驗證，再提交確認。正式版另含移除、失聯行為、遠端更新及防回收狀態。 | 示範配對與重新開機確認。 |
| 事件與通知 | 現有事件資料包含異常、恢復、更新、備份與登入等。 `/api/telegram` 管理通知設定。 | 時間軸與詳情。「標記已檢視」是原型頁面內的互動，重新整理後重設。正式版若採用此操作，需要先確認是否已有相容的儲存方式。 |
| 登入與身分確認 | `/api/login`、`/api/pin-login`、`/api/passkey-login`、`/api/sessions`。含工作階段、臨時 PIN 換碼及敏感操作的二次驗證。 | 登入與裝置設定入口。 |
| 工具與其他入口 | 流量、備份與還原、下載、雲端硬碟、加密筆記、相簿、機場起降、廣告攔截、常用連結、安全檢查、更新及外觀。另有訪客分享頁、被監看頁及還原專用頁。 | 工具與設定的入口可操作。個別功能與獨立頁面的正式流程留待選定設計後移植。 |

所有原型操作皆在瀏覽器內使用示範資料。事件篩選、切換指標與期間、配對確認及重開機確認均為互動示範。

## 瀏覽器驗證

使用 Microsoft Edge 158 實際渲染並操作。桌面視窗為 1440 × 900。手機以 390 × 844 的 CSS 視窗模擬觸控，擷取為 780 × 1688 PNG。

- A 桌面與手機通過失聯篩選、IP 搜尋、主機切換、趨勢區間、服務明細和配對示範。
- B 桌面與手機通過指標與時段切換、失聯時保留其他主機曲線、重新開機的失聯提示及驗證碼示範。
- C 桌面與手機通過選取與檢視事件、待檢視篩選、失聯資料狀態及進入相關主機。手機選單也已操作驗證。
- 預覽選單的縮圖和原型連結已確認可開啟。另檢查了 320、768 和 1024 像素寬的版面，四頁均無水平溢出。

正式 API、登入、部署和真實主機操作尚未進入本階段的驗證範圍。
