# 🛡️ VPS 哨兵

**用手機或電腦，隨時看你的 VPS 健不健康。**

在 VPS 上裝好之後，打開一個網址，就能看到處理器、記憶體、磁碟用了多少，Docker 容器有沒有掛掉，系統要不要更新。出問題還能直接傳 Telegram 通知你。

只用 Python 內建的功能，不用另外裝 Home Assistant、資料庫或其他軟體。

---

## ✨ 可以做什麼

- 📊 **即時狀態**：處理器、記憶體、磁碟、網路速度、開機多久
- 📈 **歷史曲線**：可以切換最近 30 分鐘、24 小時、7 天；資料會存檔，重開機也不會不見；電腦上把滑鼠移到曲線上，可以看到那個時間點的數值
- 📶 **每月流量統計**：本月用了多少、預估月底會用多少、每天用量，快超過上限會通知你（上限、重置日直接在網頁上設定）
- 🐳 **容器與服務**：Docker 容器、系統服務有沒有在正常執行，同一組 docker compose 的容器會自動歸在一起
- 🔄 **一鍵更新系統**：按一下按鈕，VPS 就會在背景安裝更新
- 🚩 **國旗**：自動顯示主機所在的國家，多台時一眼就分得出來
- ✏️ **自訂名稱、常用連結**：點名字旁的鉛筆圖示就能改名；也可以加上這台主機的常用網頁（例如 3x-ui 後台、n8n），名稱旁會出現 ↗ 圖示，一點就打開（好幾個時會先出現選單），而且會每分鐘檢查這些網頁打不打得開，打不開會亮紅點並通知你；網址的安全憑證快過期（剩不到 14 天）或已經過期，也會提醒你
- 🔁 **幫 3x-ui 自動續憑證**：3x-ui 的憑證（用 acme.sh 申請、要靠 80 埠驗證的那種）到了該續期的時候，如果 80 埠被 nginx 等程式佔著、acme.sh 自己續不了，哨兵會先暫停那個程式幾秒、續好憑證、再把它打開，然後通知你結果
- 🖥️ **多台一起看**：一個網址看全部的 VPS
- 🗄️ **每日自動備份**：每天清晨 4 點把 3x-ui、n8n、哨兵、Caddy／nginx、安全憑證這些設定打包並加密，每台主機都存著每一台的備份，Telegram 上也有一份（見下方）
- 💬 **Telegram 通知**：出問題、恢復、更新完成都會通知你（直接在網頁的設定裡就能開啟）
- 🔑 **登入與重開機通知**：有人從 SSH 登入主機（會寫是誰、從哪個 IP、用金鑰還是密碼），或主機重新開機，都會記在事件紀錄並通知你
- 👆 **手機金鑰登入**：在設定的「安全」裡登記手機（最多 5 支），之後登入用指紋或臉部辨識就好，不用輸入密碼。要用 https 網域網址打開哨兵才能用；原本的密碼也還是可以登入
- 🔢 **PIN 碼登入**：在設定的「安全」裡設一組 4～8 位數字，登入時輸入 PIN 碼就好。連續輸錯 5 次會暫停 15 分鐘，累計輸錯 10 次會自動關閉並通知你
- ⏳ **30 天內不用再登入**：登入頁勾選後，這台裝置 30 天內打開就直接進去；沒勾的話，關掉瀏覽器或 App 就要重新登入
- 🔒 **一鍵換密碼**：擔心密碼外流時，在設定的「安全」裡按一下就換新，舊密碼和雲端硬碟的登入馬上失效；多台一起看的話，主要那台會自動記住其他台的新密碼
- 📱 **電腦版、手機版各自設計**：電腦有大儀表板，手機可以加到主畫面當 App 用
- 🎨 **自訂外觀**：點齒輪 ⚙️ 可以換主題色、深淺色、玻璃效果、背景、文字大小，也能選擇要顯示哪些內容（設定存在各自的裝置上）

## 🚀 安裝

用 root 身分登入 VPS（如果是用一般帳號登入，先輸入 `sudo -i`），然後貼上：

```bash
git clone https://github.com/a7510049/vps-sentinel.git ~/vps-sentinel
cd ~/vps-sentinel && bash install.sh
```

第一次安裝時會先問你兩件事：

1. **全新安裝** 還是 **從備份還原**（輸入 1 或 2）
2. 要不要設定網域（有的話輸入，沒有就直接按 Enter 跳過）

接著畫面會一步一步顯示進度（`[1/4] 安裝主程式 ✓` 這樣），裝好後會出現一個網址，用手機或電腦打開就能看了（第一次打開會自動記住密碼）。

> 不想被問也可以直接指定：`bash install.sh --fresh [網域]` 是全新安裝，`bash install.sh --restore [網域]` 是從備份還原。

### 從備份還原（換新主機時最方便）

選「從備份還原」後，畫面最後會出現一個網址和一組 8 碼的還原代碼（24 小時內有效）：

1. 用電腦或手機打開那個網址
2. 選擇備份檔（`.vsbk`），輸入解開密碼，按「開始還原」
3. 網頁上會一邊顯示進度，最後一項一項告訴你 3x-ui、n8n、網站、哨兵有沒有跑起來

網域可以先不設：還原時會自動用回備份裡原本的網域（記得先到網域商把網址改指向新主機）。還原完成後，這組代碼就失效了，別人拿到也沒用。3x-ui 一樣要先用它官方的安裝指令裝好。

> 📱 **iPhone 小技巧**：用 Safari 打開網址 → 按「分享」→「加入主畫面」，就會變成一個 App。

### 有自己的網域？建議加上加密連線

1. 到買網域的網站，新增一筆 **A 紀錄**，指向你 VPS 的 IP
2. 在 VPS 上執行（換成你的網域）：

```bash
cd ~/vps-sentinel && bash install.sh 你的網域
```

網址就會變成 `https://你的網域`，比較安全。

> 如果 VPS 的 443 連接埠已經被其他服務（例如翻牆服務）使用，程式不會去搶，會自動改用 **9443**，網址就是 `https://你的網域:9443`。
>
> 如果 80 連接埠已經被 **nginx** 使用，程式也不會去搶，會請 nginx 幫忙轉交憑證驗證，你原本 nginx 上的網站不受影響。

### ⚠️ 雲端主機的防火牆

甲骨文（Oracle）、AWS、GCP 這類雲端主機，網站上還有一道防火牆要自己打開：

| 安裝方式 | 要開的連接埠（TCP） |
|---|---|
| 一般安裝 | 8787 |
| 有網域 | 80，以及 443 或 9443（看安裝完顯示的網址） |

## 📱 安卓 App（選用）

用安卓手機打開 [安卓 App 下載頁](https://github.com/a7510049/vps-sentinel/releases/tag/android)，點 `vps-sentinel.apk` 下載安裝（手機會問要不要允許安裝，選允許）。
打開後輸入主機網址（例如 `https://網域:9443`）和密碼或 PIN 碼。新版會蓋過舊版，不用先移除。

## 🔄 更新到最新版

**最簡單：直接在網頁上更新。** 點右上角齒輪 ⚙️ →「軟體更新」，有新版時按「更新」就好（有新版時齒輪上會出現小藍點）。多台會一起列出來，可以一次全部更新。

也可以在主機上手動更新：

```bash
cd ~/vps-sentinel && git pull && bash install.sh
```

你的設定（密碼、名稱、網域等）都會保留。

> 從舊版第一次升級到有「網頁更新」的版本時，需要先手動更新一次，之後就都能在網頁上更新了。

### ☁️ 雲端硬碟（選用）

想在主機上放自己的檔案？執行一行就能裝好一個網頁版的雲端硬碟（[FileBrowser Quantum](https://github.com/gtsteffaniak/filebrowser)），可以上傳、下載、分享：

```bash
cd ~/vps-sentinel && git pull && bash install.sh && bash cloud.sh 50
```

最後的數字是**容量上限（GB）**，放滿就是滿了，不會吃掉整台主機的硬碟。裝好後畫面會顯示網址；哨兵的磁碟卡片上也會出現「☁ 雲端」入口和用量，快滿或打不開時會通知你。

| 要做什麼 | 指令 |
|---|---|
| 改容量（可以加大或縮小） | `bash cloud.sh 100` |
| 更新到官方最新版（網頁上齒輪 →「軟體更新」也能按） | `bash cloud.sh 更新` |
| 打不開、連不上（自動找原因） | `bash cloud.sh 檢查` |
| 移除（檔案會保留） | `bash cloud.sh 移除` |

> 雲端硬碟會接在哨兵的網址後面（例如 `https://你的網域/cloud/` 或 `http://IP:8787/cloud/`），跟哨兵用同一個連接埠，不用另外開防火牆。沒有設定網域的主機連線不會加密，建議加上網域。
> **不用另外的帳號密碼：** 雲端硬碟跟哨兵一起登入。在哨兵網頁上點磁碟卡片的「☁ 雲端」就直接進去；直接打開雲端硬碟網址的話，會先請你登入哨兵，登入後自動帶你回去。登入一次可以用 30 天。

## ⚙️ 設定

設定檔在 `/etc/vps-sentinel-lite.conf`，用這個指令打開：

```bash
nano /etc/vps-sentinel-lite.conf
```

改完存檔後，執行 `systemctl restart vps-sentinel-lite` 才會生效。

| 項目 | 說明 |
|---|---|
| `TOKEN` | 存取密碼 |
| `SERVICES` | 想監看的系統服務，例如 `nginx,ssh` |
| `PEERS` | 其他 VPS 的網址（多台一起看，見下方） |
| `TG_BOT_TOKEN`、`TG_CHAT_ID` | Telegram 通知（建議直接在網頁上設定，見下方） |
| `ALERT_CPU`、`ALERT_MEM`、`ALERT_DISK` | 超過幾 % 算異常（預設 90） |
| `COUNTRY` | 國旗判斷錯的話，可以手動指定，例如 `JP` |
| `TRAFFIC_LIMIT_GB`、`TRAFFIC_RESET_DAY`、`TRAFFIC_COUNT` | 每月流量上限、重置日、計算方式（建議直接在網頁上設定） |
| `BACKUP`、`BACKUP_HOUR` | 每日備份開或關（`on`／`off`，預設開）、每天幾點備份（預設 4，主機的時間） |
| `BACKUP_PATHS` | 還想一起備份的資料夾或檔案，用逗號隔開 |

### Telegram 通知

在網頁右上角點齒輪 ⚙️ →「Telegram 通知」，照著畫面做：

1. 在 Telegram 搜尋 **@BotFather**，傳送 `/newbot`，取好名字後它會給你一串**機器人密碼**，貼到網頁上
2. 在 Telegram 找到你剛建立的機器人，隨便傳一句話給它（要傳到群組，就把機器人加進群組再講一句話）
3. 回到網頁按「自動尋找」，選要傳去的地方，按「儲存」

儲存時會先傳一則訊息給你確認。還可以選「通知保留多久」（1 小時～2 天），時間到會自動從 Telegram 刪掉，聊天室不會越堆越多。

通知的內容跟網頁上的「事件紀錄」一樣：出問題、需要留意（例如需要重新開機、流量快用完）、恢復正常、系統更新完成、有人登入主機、主機重新開機、密碼換新、登記或刪除手機金鑰，以及其他主機連不上或恢復連線。

多台一起看的話，**只要在主要那台設定**就好，它會一起通知其他台的狀況（其他台不要再設定，不然會收到兩次）。

> 建議另外建一個專門的機器人，不要跟 n8n 等其他程式共用。

### 每日備份

裝好就會自動開始，不用設定。每天清晨 4 點（主機的時間），哨兵會把這台主機上重要的設定打包並加密：

- **3x-ui**：使用者、節點設定（`/etc/x-ui`）
- **n8n**：所有的工作流程和帳號連線（自動找到 n8n 容器的資料）
- **哨兵自己**、**Caddy／nginx** 的設定、雲端硬碟的設定
- **安全憑證**：acme.sh 的憑證和帳號（含 Cloudflare 設定），還有 3x-ui 設定裡用到的憑證和私鑰，放在哪個資料夾都會找到
- **排程**：root 的 crontab（自己加的定時工作）

可以重新下載的東西不會備份，例如 Docker 映像檔、3x-ui 和哨兵的程式本身、系統套件，還原時會自動重新安裝。雲端硬碟裡你放的檔案也不在備份裡（太大了），請自己另外留一份重要的。

資料庫就算正在使用中，也會拿到完整的一份。每台主機的每個資料夾都只留最近 7 份，舊的自動刪掉。

**每台主機都存著每一台的備份**：雲端硬碟裡的「哨兵備份」資料夾，一台主機一個資料夾（沒有雲端硬碟的話放在主機上）。資料夾和檔案都用主機在網頁上顯示的名稱，檔名像「主機名稱 2026-10-13 04.00.vsbk」，時間是你手機或電腦的時區（所有主機一樣）；在網頁上幫主機改名，備份也會跟著換成新名稱。多台一起看的話，主要那台每天會把自己的備份送到其他台、也把其他台的拿回來，所以任何一台壞掉，另一台都還有全部的備份。有設定 Telegram 通知的話，Telegram 上也會有一份（安靜傳送，不會響）：每台主機只留最新那一份，新的傳成功後才刪掉前一天的；通知是傳到你跟機器人的私人對話時，訊息裡會附上打碼的解開密碼，傳到群組就不附。**每一份備份都有自己的密碼**，Telegram 上給的那組只打得開那一份，就算外流也不會連帶打開其他天的備份；網頁「設定 → 備份」裡的總密碼則是每一份都打得開（還原時兩種都可以用）。密碼跟檔案放在一起，Telegram 那份就靠你的 Telegram 帳號保護，建議開 Telegram 的「兩步驟驗證」。

**加密**：備份檔是哨兵專用的格式（`.vsbk`），裡面用的是標準、成熟的加密方法：

- 密碼先經過 scrypt 處理（故意算得很慢又吃記憶體，就算有人拿去猜密碼也要猜很久）
- 內容用 AES-256 加密（由系統的 openssl 來算）
- 加上 HMAC-SHA256 簽章：密碼不對、或檔案被改過一點點，都會被發現，不會解出錯的東西

所有主機共用同一組解開密碼，在網頁的「設定 → 備份」裡，點一下才會顯示，**請另外記在安全的地方**。也可以改成自己想的密碼（至少 8 個字），所有主機會一起換；以前的備份還是要用舊密碼開，所以舊密碼也請留著。

在網頁的「設定 → 備份」可以看上次備份的結果、每台主機存著哪些備份、馬上備份一次、下載最新的備份。備份失敗會通知你。

**還原**：一個指令就會把檔案放回去，3x-ui、n8n、網站和哨兵也會自動重新啟動，最後一項一項告訴你有沒有跑起來。還原前，主機上原本的檔案會先另外留一份（放在 `/root/還原前的檔案-時間.tar.gz`），放錯了也退得回去。

- **讓主機回到前幾天的樣子**：在那台主機上執行下面這行，從清單挑一份、輸入解開密碼

  ```bash
  sudo python3 ~/vps-sentinel/sentinel.py --restore
  ```

- **整台搬到新主機**（原本那台壞掉時）：先到網域商把網址改指向新主機，再到還活著那台的網頁「設定 → 備份 → 怎麼還原？」，選要還原哪一台，複製產生的指令貼到新主機上執行。指令會下載專案、用一個 24 小時內有效的連結拿到加密的備份檔，再整台還原：新主機缺的 Docker、nginx、哨兵會自動裝好，n8n 容器照原本的設定建回來。3x-ui 要先用它官方的安裝指令裝好（裝的時候問的問題都按 Enter），還原時會用回原本的設定。
- 只想把備份檔解開看看：`python3 sentinel.py --decrypt 備份檔.vsbk`（解開成 .tar.gz）

### 多台 VPS 一起看

1. 每一台 VPS 都照上面的方法安裝
2. 在你要當「主要」的那一台，打開設定檔，填上其他台的網址和密碼：

```
PEERS=東京=https://tokyo.example.com,大阪=https://osaka.example.com|大阪那台的密碼
```

（密碼跟主要那台一樣的話，`|密碼` 可以省略）

之後只要打開主要那台的網址，就能看到全部。

## 🧰 常用指令

| 要做什麼 | 指令 |
|---|---|
| 看程式有沒有在跑 | `systemctl status vps-sentinel-lite` |
| 看執行記錄 | `journalctl -u vps-sentinel-lite -n 50` |
| 忘記密碼 | `grep TOKEN /etc/vps-sentinel-lite.conf` |
| 重新啟動 | `systemctl restart vps-sentinel-lite` |

### 完全移除

```bash
systemctl disable --now vps-sentinel-lite
rm -rf /opt/vps-sentinel-lite /var/lib/vps-sentinel-lite /etc/vps-sentinel-lite.conf /etc/systemd/system/vps-sentinel-lite.service /etc/caddy/sites/vps-sentinel.caddy
systemctl reload caddy 2>/dev/null; systemctl daemon-reload
```

## 📦 從舊版（Home Assistant 版）升級

舊版需要 Home Assistant 和 MQTT，現在都不需要了。裝好新版後，可以用這個工具清掉舊版留下的東西：

```bash
cd ~/vps-sentinel && bash cleanup-old.sh
```

它會先列出找到的舊東西，確認後才會刪除，不會動到新版、Docker 裡的其他容器（例如 n8n）。
