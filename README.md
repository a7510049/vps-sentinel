# 岬角 Cape

**屬於你的私人雲，從一台 VPS 開始。**

哨站把你的 VPS 變成一座完整的個人據點。即時監控每一台主機，異常第一時間透過 Telegram 通知；同一個入口，還有雲端硬碟、相簿分享、加密筆記、廣告攔截與即時航班。

Cape 5.59 使用原有哨站 Python 服務和資料目錄。下方包含原有後端功能及主機操作說明，Cape 介面的支援範圍請見 [PRODUCT.md](PRODUCT.md)。

## ✨ 功能一覽

### 監控，一目了然

- 📊 **即時指標**：處理器、記憶體、磁碟、負載、網路速度、連線數與磁碟讀寫，提供 30 分鐘、24 小時與 7 天趨勢圖。
- 🔥 **資源洞察**：最耗資源的前 5 個程序，以及完整的主機規格（處理器型號、記憶體、IP）。
- 📶 **流量管理**：本月用量、每日明細、月底預估，接近上限時主動提醒。
- 🟩 **上線紀錄**：每台主機 30 天的可用性，一天一格，哪天中斷一看便知。
- 🐳 **服務狀態**：Docker 容器與系統服務是否正常運作，清清楚楚。
- 🖥️ **主機清冊**：異常主機自動排在前面。可搜尋或依狀態篩選，點選主機後在同一頁查看趨勢與詳情。

### 通知，恰到好處

- 💬 **Telegram 通知**：故障與恢復、登入事件、重新開機、更新完成、備份失敗，每則訊息都以狀態符號開頭，舊訊息自動清理，聊天室永保整潔。
- 🔐 **主動預警**：安全憑證即將到期、常用連結無法開啟，都會提前告訴你。
- 🧠 **即時警報**：記憶體不足、系統強制終止程序（例如 xray、n8n）時，第一時間通知。
- 📮 **不漏接**：Telegram 暫時無法連線時，通知會依序排隊，恢復後自動補傳並標註原始時間。

### 工具，一應俱全

所有工具都在「工具」分頁，一次登入，全部可用。

#### ✈️ 航班動態

桃園、松山、台中、高雄四座機場的即時起降資訊。

- **翻牌看板**：重現機場經典的翻牌顯示，依官方航班表呈現時間、登機門與狀態，抵達、出發、機坪、貨機分開檢視。
- **雷達圖**：海岸線、地形與常用航路一應俱全，支援全螢幕縮放與拖曳；點選任一架飛機，即可查看高度、速度與照片。
- **登機證式詳情**：桃園出發班機附航廈地圖並標出登機門，按下「我在哪」即可知道距離登機門多遠。
- **分享**：產生短連結傳給朋友，自訂有效期限與可用裝置數量，也能隨時收回。
- **資料來源**：[adsb.fi](https://adsb.fi)、[OpenSky](https://opensky-network.org) 等愛好者共享的接收站，僅限個人使用。台中、高雄周邊主要仰賴 OpenSky，在「設定 → OpenSky 帳號」填入免費帳號，即可取得每日 4,000 點的查詢額度。
- **圖資致謝**：地形 Mapzen Terrain Tiles／SRTM、導航台 OurAirports、跑道與機坪 © OpenStreetMap 貢獻者、飛機照片 [Planespotters](https://www.planespotters.net)（標註攝影者）。

#### ☁️ 雲端硬碟

屬於你自己的網頁版檔案空間，與哨站共用登入，支援整顆 AES-256 加密——即使硬碟被複製走，也無法開啟。

#### ⬇️ 遠端下載

貼上連結，主機替你下載到雲端硬碟。大型檔案自動分段並行下載，速度更快。

#### 📝 加密筆記

搭配 Joplin App，將筆記同步到自己的主機。筆記在手機端就已加密，主機只保存密文，並納入每日備份。

#### 🖼️ 相簿分享

從雲端硬碟選一個資料夾，就是一本精美的線上相簿。

- **為瀏覽而生**：電影般的開場、每日封面、最多愛心的照片自動成為「精選」；看大圖時，背景會透出照片本身的色彩，整頁配色也隨封面變化。支援滑動切換、雙指縮放、全螢幕幻燈片，資料夾裡放一首歌就有配樂。
- **說好旅行的故事**：照片依城市分類，同一趟旅程依拍攝時間在地圖上畫出路線；時間軸一拖，就能看到當時身在何處、拍下了什麼。每天自動寫下一句摘要——「早上在哪、下午到哪、走了幾公里」，並附上當天天氣。
- **聰明整理**：自動評估清晰度與曝光，相似照片與連拍收成一疊，只露出最好的一張；一天的照片依時間與地點自動分段。可搜尋「黃金時刻」「晴天」「紅色」「第 2 天」，也能依顏色排成一道彩虹。
- **專業級細節**：完整 EXIF 資訊——相機品牌標誌、鏡頭、光圈、快門、ISO、直方圖、主色調、相片風格、底片模擬與 LUT。忠實保留 P3、Adobe RGB 色彩空間，HDR 照片在支援的螢幕上依然是 HDR；直接支援 iPhone HEIC、原況照片、影片、GIF，以及 Sony、Canon、Nikon、富士、松下等相機原始檔。
- **一起互動**：朋友可以按愛心、送出 😂 😮 👍 🥹 表情、留言與回覆，並在留言簿為整本相簿留下一句話；也可以開放朋友一起上傳照片（可設定需要你審核、總容量上限，每人各自一個分頁與資料夾）。
- **隱私由你掌控**：可設定密碼、有效期限與裝置數量（已看過的裝置可以移除），可只分享挑選的照片、隱藏拍攝地點、加上浮水印，並決定下載提供原圖、壓縮圖或不開放。訪客看到的一律是壓縮後的圖片，頁面內容無法選取或複製，隨時都能收回。

#### 🛡️ 廣告攔截（AdGuard Home）

一鍵部署，手機上的廣告與追蹤網址全面阻擋。

- 僅使用加密 DNS：iPhone 安裝描述檔、電腦掃描 QR 碼、Android 設定私人 DNS 即可。
- 智慧分流：國際網站查詢國際 DNS，中國大陸網站才查詢大陸 DNS。
- 額外阻擋中文廣告、詐騙、釣魚與惡意網站；最近或最常被擋的網址，一鍵即可放行。
- 擁有兩台以上主機時，會互相從外部測試連線，並在雲端防火牆未開放時提醒你。
- AdGuard Home 管理頁面同樣需要通過驗證才能開啟。

#### 🔗 常用連結

一鍵開啟 3x-ui、n8n 等管理後台，同時確認它們是否能正常連線。

#### 🗄️ 每日備份

每天自動加密備份重要設定，每台主機都保存所有主機的備份。

### 安全，從設計開始

- 🔑 **無密碼登入**：支援通行金鑰（指紋、臉部辨識）與 PIN 碼，可選擇 30 天內免再次登入。所有登入裝置一覽無遺，手機遺失時可單獨登出。
- 🚪 **安全檢查**：一個開關即可停用 SSH 密碼登入（會先為你設定好金鑰）、限制 root 僅能用金鑰登入、多次失敗自動封鎖、自動安裝安全更新。任何一項被關閉，都會透過 Telegram 通知你。
- 🎲 **安全的第一步**：首次安裝會產生隨機臨時 PIN 碼，網址不含任何密碼；登入後必須先設定自己的 PIN 碼。
- 🔄 **敏感操作二次驗證**：從網頁重新開機需要 Telegram 驗證碼。
- 🧩 **配對不傳金鑰**：新增主機使用一次性配對碼，兩台主機各自算出連線金鑰，金鑰從不在網路上傳輸。
- 🗝️ **雙層加密**：密碼、Telegram 設定、連線金鑰、PIN 碼與登入資料，一律以 AES-256-GCM 與 ChaCha20-Poly1305 雙重加密。即使設定檔被複製，也只是一串亂碼。
- 🔒 **全程加密連線**：僅接受 TLS 1.3，並啟用 HSTS；沒有網域時也會使用自簽憑證加密。

### 還有更多

- ⬆️ **一鍵更新**：在網頁上更新哨站、雲端硬碟與系統；新版若無法啟動，自動回復舊版。
- 🌲 **Oracle 免費主機防回收**：每天分段將處理器使用率維持在 25%，避免被判定為閒置而回收。
- 🎨 **個人化外觀**：深淺色模式、多種主題色與配色風格，文字大小隨心調整。

## 🚀 開始使用

以 root 登入 VPS（一般帳號請先執行 `sudo -i`），貼上：

```bash
git clone https://github.com/a7510049/vps-sentinel.git ~/vps-sentinel
cd ~/vps-sentinel && bash install.sh
```

部署環境為使用 systemd 的 Linux。安裝程式會從 Node.js 官方來源下載並驗證專用執行檔，保留既有系統的 Node.js。執行環境支援 x86_64、arm64、ppc64le 和 s390x，須具備 Node.js 24 所需的 Linux 系統函式庫。

安裝程式只會問你兩件事：

1. **全新安裝**，或**從備份還原**
2. 網域（沒有的話直接按 Enter）

完成後，畫面會顯示網址與臨時 PIN 碼。開啟網址、輸入 PIN 碼，再設定一組你自己的，就完成了。

忘記 PIN 碼？在主機上執行 `sudo python3 /opt/vps-sentinel-lite/sentinel.py --new-pin` 即可重設。

### 使用自己的網域

先在網域商新增一筆 **A 紀錄**指向 VPS 的 IP，再執行：

```bash
cd ~/vps-sentinel && bash install.sh 你的網域
```

網址會變成 `https://你的網域`。若 443 埠已被佔用（例如 3x-ui），會自動改用 **9443**；80 埠已被 nginx 佔用時也不會搶用，現有網站完全不受影響。

### ⚠️ 雲端防火牆設定

Oracle、AWS、GCP 等雲端主機，請到主機商的控制台開放以下 TCP 連接埠：

| 安裝方式 | 需開放的連接埠 |
|---|---|
| 沒有網域 | 8787 |
| 有網域 | 80，以及 443 或 9443（依安裝完成後顯示的網址） |

### 📱 加入手機主畫面

- **iPhone**：在瀏覽器開啟網址 →「分享」→「加入主畫面」。
- **Android**：在 Chrome 開啟網址 → 右上角選單 →「加到主畫面」。

## 🖥️ 新增主機

先在每台 VPS 上完成安裝。新主機安裝完成時，畫面最後會顯示一組以 `VS-` 開頭的**配對碼**（24 小時內有效，僅限使用一次）：

1. 在主控主機的首頁，按下主機列表最後的「新增主機」。
2. 貼上配對碼。

完成後，只要打開主控主機，就能看到所有主機。配對碼過期時，可在新主機的「設定 → 主機 → 配對碼」重新產生。

**自動接手，不怕斷線**：被加入的主機，自己的網頁只會顯示「由誰監看中」。若主控主機 5 分鐘未連線，其中一台會透過 Telegram 通知你，之後每台主機各自回報異常；主控主機恢復後，再自動交還監看工作。

## 🔄 更新

在網頁「設定 → 主機」，有新版本時按「更新」；多台主機都有新版時，可一次「全部更新」。

進度視窗會即時顯示每台主機的「下載、安裝、重新啟動、完成」，完成後網頁自動切換為新版。若新版無法啟動，系統會自動回復舊版並通知你。

也可以在主機上手動更新：

```bash
cd ~/vps-sentinel && git pull --ff-only origin main && sudo bash install.sh
```

更新會沿用 `/etc/vps-sentinel-lite.conf`、其指定的資料目錄及既有服務設定。原有主機、認證、使用者設定與加密資料會繼續使用原路徑，Cape 規則另存在該資料目錄下的 `cape/`。安裝程式會檢查主服務和 Cape 規則服務是否就緒，並沿用既有的程式檔回復機制。

## ☁️ 雲端硬碟（選用）

一行指令，部署網頁版雲端硬碟（[FileBrowser Quantum](https://github.com/gtsteffaniak/filebrowser)），支援上傳、下載與分享：

```bash
cd ~/vps-sentinel && sudo bash cloud.sh 50
```

數字代表**容量上限（GB）**。空間用滿即止，不會佔滿整台主機的磁碟。安裝後，在「工具」分頁點選「雲端硬碟」即可直接進入，無需另外的帳號密碼。

| 操作 | 指令 |
|---|---|
| 調整容量 | `sudo bash cloud.sh 100` |
| 更新（也可在網頁「設定 → 主機」操作） | `sudo bash cloud.sh 更新` |
| 疑難排解 | `sudo bash cloud.sh 檢查` |
| 移除（檔案會保留） | `sudo bash cloud.sh 移除` |

### 遠端下載影片

下載 YouTube、Bilibili 等網站的影片，需先在主機上安裝 [yt-dlp](https://github.com/yt-dlp/yt-dlp)（搭配 ffmpeg 可取得最佳畫質）；安裝後，哨站會每天自動更新它。

YouTube 會封鎖機房 IP：若主機已安裝 Cloudflare WARP（`127.0.0.1:40000`），會自動透過它連線，也可以在設定檔填入 `YT_PROXY`。若仍被封鎖，可在下載視窗貼上網站的登入資料（Cookie）。

## 🗄️ 每日備份與還原

安裝完成即自動啟用，無需任何設定。每天清晨 4 點，自動加密打包以下內容：

- 3x-ui、n8n、哨站、Caddy／nginx 與雲端硬碟的設定
- 安全憑證（acme.sh、3x-ui 使用的憑證與私鑰）以及 root 的排程（crontab）

可重新下載的內容（Docker 映像檔、程式本身）不納入備份；雲端硬碟中的檔案因體積較大也不備份，重要檔案請另行保存。

**儲存位置**：每台主機都保存所有主機的備份，位於雲端硬碟的「哨兵備份」資料夾（未安裝雲端硬碟時存放於主機上），每台保留最近 7 份。若已設定 Telegram，也會靜音傳送最新一份；超過 50 MB 時自動分段，還原時一次選取所有分段即可。

**備份密碼**：總密碼位於「工具 → 每日備份」，點擊才會顯示，可開啟任何一份備份——**請務必另外妥善保存**。每份備份也有各自的密碼（會以遮蔽形式附在 Telegram 私人對話中），僅能開啟該份備份。

**加密技術**：scrypt（大幅拖慢暴力破解）＋ AES-256 ＋ HMAC-SHA256（密碼錯誤或檔案遭竄改都能偵測）。

### 還原

- **遷移到新主機**：在新主機執行 `bash install.sh`，選擇「從備份還原」，透過畫面提供的網址上傳備份檔（`.vsbk`）並輸入密碼。網頁會顯示還原進度，並在最後回報每項服務是否正常運作。3x-ui 請先以官方指令安裝；別忘了將網域改為指向新主機。
- **回到前幾天的狀態**：在該主機執行

  ```bash
  sudo python3 ~/vps-sentinel/sentinel.py --restore
  ```

  從清單中選擇一份並輸入密碼。原有檔案會先另存為 `/root/還原前的檔案-時間.tar.gz`。
- **只想解開檢視**：`python3 sentinel.py --decrypt 備份檔.vsbk`

## ⚙️ 進階設定

絕大多數設定都能在網頁上完成。少數進階選項位於 `/etc/vps-sentinel-lite.conf`，修改後請執行 `systemctl restart vps-sentinel-lite`。

| 項目 | 說明 |
|---|---|
| `SERVICES` | 要監看的系統服務，例如 `nginx,ssh` |
| `ALERT_CPU`、`ALERT_MEM`、`ALERT_DISK` | 超過多少 % 視為異常（預設 90） |
| `COUNTRY` | 國旗判斷有誤時手動指定，例如 `JP` |
| `BACKUP`、`BACKUP_HOUR` | 每日備份開關（`on`／`off`）與備份時間（預設 4 點） |
| `BACKUP_PATHS` | 額外要備份的資料夾或檔案，以逗號分隔 |
| `KEEPALIVE` | 設為 `off` 可關閉 Oracle 防回收 |
| `YT_PROXY` | 下載影片使用的代理，例如 `socks5://127.0.0.1:40000` |

## 🧰 常用指令

| 操作 | 指令 |
|---|---|
| 查看運作狀態 | `systemctl status vps-sentinel-lite` |
| 查看執行紀錄 | `journalctl -u vps-sentinel-lite -n 50` |
| 重設 PIN 碼 | `sudo python3 /opt/vps-sentinel-lite/sentinel.py --new-pin` |
| 重新啟動 | `systemctl restart vps-sentinel-lite` |

### 完全移除

```bash
systemctl disable --now vps-sentinel-lite
rm -rf /opt/vps-sentinel-lite /var/lib/vps-sentinel-lite /etc/vps-sentinel-lite.conf /etc/systemd/system/vps-sentinel-lite.service /etc/caddy/sites/vps-sentinel.d /etc/caddy/sites/vps-sentinel.caddy
systemctl reload caddy 2>/dev/null; systemctl daemon-reload
```
